Spotify Clone (HTML & CSS)

A responsive clone of the Spotify web player UI built using HTML and CSS. This project replicates the layout and design of Spotify’s homepage for learning and practice purposes.

Features of Spotify_Clone

1. Spotify-like user interface
2. Sidebar with Home, Search, Library
3. Music cards (Trending / Top 50)
4. Music player UI (play, pause, progress bar)
5. Responsive layout
6. Clean and modern design
